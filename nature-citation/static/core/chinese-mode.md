# Default output language

Unless the user explicitly requests another language:

- Return explanations, segment notes, evidence notes, risk statements, summaries, and report headings in Simplified Chinese.
- Preserve publication titles, author names, journal names, DOI, PMID, database names, file formats, standard abbreviations, and precision-critical terminology in their source language.
- Accept manuscript text in any language. Search using the language most effective for the field; for Chinese scientific text, normally use English concept queries unless the topic is China-specific or concerns Chinese-language scholarship.
- Preserve the exact source segment and translate it into one or more English search claims.
- Flag overclaiming clearly in Chinese: `强支撑`, `部分支撑`, `背景支撑`, `不建议引用为该句支撑`.
- Do not present a paper as supporting the claim merely because its title is related.
