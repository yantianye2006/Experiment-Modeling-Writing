# 各会议格式规范

## NeurIPS (Neural Information Processing Systems)

- **页数限制**: 正文 9 页，参考文献不计
- **格式**: 双栏，`neurips_20XX.sty`
- **匿名审稿**: 是（双盲）
- **附录**: 允许，不计入页数限制
- **程式码**: 鼓励提交，可附于 supplementary
- **审稿周期**: 约 3-4 个月
- **录取率**: ~25%
- **重点审查**: 新颖性、理论严谨度、实验完整性

## ICLR (International Conference on Learning Representations)

- **页数限制**: 正文 8 页 + 不限附录
- **格式**: 双栏，`iclr20XX_conference.sty`
- **匿名审稿**: 是（双盲），OpenReview 公开审稿
- **特色**: 审稿意见公开可查
- **程式码**: 强烈鼓励
- **审稿周期**: 约 3 个月
- **录取率**: ~30%
- **重点审查**: 清晰度、贡献显著性、可重现性

## ICML (International Conference on Machine Learning)

- **页数限制**: 正文 8 页，参考文献不计
- **格式**: 双栏，`icml20XX.sty`
- **匿名审稿**: 是（双盲）
- **附录**: 允许
- **审稿周期**: 约 3-4 个月
- **录取率**: ~25%
- **重点审查**: 技术深度、创新性

## ACL / EMNLP / NAACL (NLP 系列)

- **页数限制**: 长论文 8 页，短论文 4 页（+参考文献）
- **格式**: 双栏，ACL style
- **匿名审稿**: 是（双盲）
- **ARR 系统**: ACL Rolling Review 统一审稿
- **录取率**: ~22-25%
- **重点审查**: 语言学动机、baseline 完整性、error analysis

## CVPR / ECCV / ICCV (Computer Vision 系列)

- **页数限制**: 正文 8 页 + 参考文献 (CVPR/ICCV)，14 页 (ECCV)
- **格式**: 双栏，各自 style file
- **匿名审稿**: 是（双盲）
- **supplementary**: 允许影片与额外结果
- **录取率**: ~25-30%
- **重点审查**: 视觉结果品质、与 SOTA 比较、ablation 完整性

## AAAI (Association for the Advancement of AI)

- **页数限制**: 正文 7 页 + 1 页参考文献
- **格式**: 双栏，AAAI style
- **匿名审稿**: 是（双盲）
- **录取率**: ~20%

## 通用注意事项

### 投稿前检查清单

- [ ] 页数是否符合限制
- [ ] 是否使用正确的 style file 和年份版本
- [ ] 匿名化是否完整（姓名、机构、致谢、自引）
- [ ] 参考文献格式是否正确
- [ ] 图表是否清晰可读（列印品质）
- [ ] Supplementary material 是否在大小限制内

### 常见格式错误

1. 使用旧版 style file
2. 正文超过页数限制
3. 匿名化不完整（忘记移除致谢）
4. 图片解析度太低
5. 参考文献缺少年份或会议名称
