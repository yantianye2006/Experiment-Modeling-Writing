# 收敛流程与筛选标准

本文件说明如何从多个候选 idea 中系统化地筛选、合并与精炼，最终收敛至一个最佳研究构想。

---

## 一、筛选标准

### 1.1 新颖性（Novelty）

评估 idea 与现有工作的差异程度。

| 等级 | 说明 |
|------|------|
| 5 — 开创性 | 提出全新的问题或方法，文献中找不到类似工作 |
| 4 — 高度新颖 | 有显著的差异化，即使有相关工作也明确不同 |
| 3 — 中度新颖 | 有新的元素，但整体架构或方法有先例 |
| 2 — 低度新颖 | 主要是对现有方法的小改进或直接应用 |
| 1 — 无新颖性 | 已被做过或极为类似的工作已存在 |

**判定依据**：
- 文献搜索阶段的结果
- 是否提出新的问题定义？
- 是否引入新的方法或视角？
- 是否有新的理论洞见？

### 1.2 可行性（Feasibility）

评估在现有条件下完成研究的可能性。

| 等级 | 说明 |
|------|------|
| 5 — 高度可行 | 资源充足，技术成熟，可在预定时间内完成 |
| 4 — 大致可行 | 有些挑战但可克服，风险可控 |
| 3 — 有条件可行 | 需要特定资源或解决特定技术难题 |
| 2 — 勉强可行 | 重大技术或资源障碍，成功机率不高 |
| 1 — 不可行 | 现有条件下无法完成 |

**判定依据**：
- 是否有足够的计算资源（GPU、记忆体、储存）？
- 是否有可用的资料集？
- 是否有可复现的 baseline？
- 预计需要多长时间？是否在截止日期内可完成？
- 是否需要特殊的领域知识或合作者？

### 1.3 影响力（Impact）

评估研究成果对领域的潜在贡献。

| 等级 | 说明 |
|------|------|
| 5 — 变革性 | 可能改变领域的研究方向或范式 |
| 4 — 高影响 | 对领域的重要问题有实质贡献 |
| 3 — 中度影响 | 对特定子问题有有意义的推进 |
| 2 — 低影响 | 增量式的改进，影响范围有限 |
| 1 — 极低影响 | 解决的问题太小或太偏门 |

**判定依据**：
- 有多少研究者/使用者会关心这个问题？
- 这个成果是否能被其他研究引用或使用？
- 是否能推动下游应用？
- 发表在什么层级的会议/期刊？

### 1.4 时效性（Timeliness）

评估 idea 是否处于合适的时间窗口。

| 等级 | 说明 |
|------|------|
| 5 — 完美时机 | 相关技术刚成熟，社群正在关注，竞争尚未饱和 |
| 4 — 良好时机 | 方向正在上升期，有足够的发展空间 |
| 3 — 中性 | 时机不算特别好或坏 |
| 2 — 略晚 | 方向开始饱和或失去关注度 |
| 1 — 过时 | 方向已过时或竞争极为激烈 |

**判定依据**：
- 这个方向最近是否有重要的新突破或新资源？
- 顶会中相关论文的数量趋势如何？
- 主要研究团队是否仍在投入？
- 是否有太多竞争者正在做类似的事？

### 1.5 个人兴趣（Personal Interest）

评估个人对这个 idea 的热情与动机。

| 等级 | 说明 |
|------|------|
| 5 — 非常兴奋 | 迫不及待想开始，愿意投入大量时间 |
| 4 — 有兴趣 | 觉得有趣，愿意深入探索 |
| 3 — 中性 | 不特别兴奋也不排斥 |
| 2 — 勉强 | 不太有兴趣，但知道有价值 |
| 1 — 不感兴趣 | 即使有价值也不想做 |

**为什么个人兴趣重要**：
- 研究是长期投入，没有热情很难坚持
- 对问题有直觉通常来自深层的兴趣
- 兴趣驱动的研究往往有更深入的洞见
- 写论文和做报告时，热情会感染读者和听众

## 二、收敛流程

### 2.1 第一轮：淘汰（Eliminate）

**目的**：快速移除明显不适合的候选 idea。

**淘汰条件**（满足任一即淘汰）：

1. **新颖性不足**
   - 文献搜索发现几乎相同的工作已存在
   - 且无法找到有意义的差异化切入点

2. **根本不可行**
   - 缺乏必要的资料且无法取得
   - 计算需求远超可用资源
   - 需要的技术目前尚不存在

3. **问题不成立**
   - 经过思考发现问题的前提假设有误
   - 问题实际上已被解决或不重要

**操作方式**：
- 对每个候选 idea 快速过一遍淘汰条件
- 被淘汰的 idea 标记原因后移至「淘汰区」
- 不确定是否该淘汰的 idea 暂时保留
- 预期淘汰 30-50% 的候选

### 2.2 第二轮：合并（Merge）

**目的**：将相关或互补的 idea 合并为更强的候选。

**合并判定**：

1. **同源合并**
   - 两个 idea 源自同一个问题，只是解法不同
   - 合并为：同一个问题 + 最佳解法的组合

2. **互补合并**
   - 两个 idea 各自解决问题的不同面向
   - 合并为：同时解决多个面向的整合方案

3. **层次合并**
   - 一个 idea 是另一个的子集或特例
   - 合并为：保留更通用的版本，特例作为第一个实验

**操作方式**：
- 将存活的 idea 两两比较
- 标记可能合并的配对
- 评估合并后是否真的更好（有时 1+1 < 2）
- 合并后的 idea 给予新的标题和描述

### 2.3 第三轮：精炼（Refine）

**目的**：将模糊的 idea 转化为具体的研究计划。

**精炼步骤**：

1. **问题具体化**
   - 将广泛的问题缩小到可在一篇论文中处理的范围
   - 明确 input/output 的定义
   - 明确评估指标

2. **方法具体化**
   - 构想主要的技术方案
   - 辨识关键的技术挑战
   - 构想至少两种可能的解法

3. **贡献具体化**
   - 明确列出预期的研究贡献（2-3 点）
   - 区分主要贡献与次要贡献
   - 确认贡献足以支撑一篇论文

4. **实验具体化**
   - 确定使用的资料集
   - 确定比较的 baseline 方法
   - 确定评估指标
   - 构想初步的实验方案

**精炼后的格式**：

```
## Idea: [标题]

### 问题
[一句话描述要解决的问题]

### 动机
[为什么这个问题重要？为什么现在要做？]

### 方法概要
[2-3 句话描述你打算怎么做]

### 预期贡献
1. [贡献一]
2. [贡献二]
3. [贡献三]（可选）

### 实验计划
- 资料集：[列出]
- Baseline：[列出]
- 指标：[列出]

### 风险
- [主要风险及应对]
```

### 2.4 第四轮：评分与排序

**目的**：使用量化方法对精炼后的候选进行排序。

详细的评分矩阵请参见 [evaluation-matrix.md](evaluation-matrix.md)。

**操作方式**：
1. 为每个候选 idea 在五个维度上打分（1-5）
2. 计算加权总分
3. 按总分排序
4. 重点比较前 2-3 名

### 2.5 第五轮：最终决策

**目的**：从前几名中选定一个 idea。

**决策考量**：

1. **量化结果**：加权总分最高的是哪个？
2. **直觉判断**：你最想做的是哪个？
3. **风险评估**：哪个的风险最可控？
4. **策略考量**：
   - 对你的职业发展最有利的是哪个？
   - 最适合你目前研究团队的是哪个？
   - 最适合你的时间限制的是哪个？

**当理性与直觉冲突时**：
- 花时间厘清冲突的原因
- 可能你的直觉捕捉到了某些量化分析遗漏的因素
- 与信任的人讨论
- 如果无法解决冲突，倾向于选择你更有热情的那个

## 三、常见陷阱

### 3.1 确认偏误（Confirmation Bias）

**表现**：
- 只搜索支持自己偏好 idea 的文献
- 忽视或贬低对自己 idea 不利的证据
- 对喜欢的 idea 宽容评分，对不喜欢的严格评分

**防范方法**：
- 刻意搜索反面证据
- 请他人独立评估你的候选 idea
- 对每个 idea 列出「失败的理由」清单
- 使用盲评：将 idea 匿名化后评分

### 3.2 沉没成本（Sunk Cost Fallacy）

**表现**：
- 因为已经花了很多时间研究某个 idea 而不愿放弃它
- 明知一个 idea 有严重问题，但因为已有初步结果而继续
- 「都已经做了这么多了，不能白费」的想法

**防范方法**：
- 提醒自己：过去投入的时间已经无法收回
- 问自己：如果现在从零开始，我还会选择这个 idea 吗？
- 设定明确的 checkpoint：在特定时间点评估是否应该转向
- 将过去的工作视为「学习成本」而非「浪费」

### 3.3 新奇偏误（Novelty Bias）

**表现**：
- 过度追求新颖而忽视可行性
- 选择最「酷」的 idea 而非最「好」的 idea
- 忽视简单但有效的方法，追求复杂但未经验证的方法

**防范方法**：
- 在评分时给予可行性和影响力足够的权重
- 问自己：新颖是否带来了实质的好处？
- 考虑「最小可行研究」：新颖的核心是否可以用简单的方式验证？

### 3.4 从众效应（Bandwagon Effect）

**表现**：
- 因为某个方向很热门就选择做
- 看到很多人做就觉得这个方向一定好
- 害怕做冷门的方向

**防范方法**：
- 区分「有价值」和「很热门」——二者不完全相同
- 热门方向意味著更多竞争，需要更强的差异化
- 冷门方向可能有高影响的论文机会，因为竞争少
- 问自己：如果这个方向没有人做，我还会觉得它有价值吗？

### 3.5 完美主义（Perfectionism）

**表现**：
- 等待「完美」的 idea 出现而迟迟不开始
- 总觉得 idea 还不够好、需要再想想
- 对每个 idea 都能找到缺点而无法做出选择

**防范方法**：
- 认知到不存在完美的 idea——所有 idea 在开始时都有缺陷
- 设定明确的截止日期，到期就必须做出选择
- 接受「足够好」即可开始——idea 会在研究过程中持续演化
- 记住：一个已完成的「好」研究，远胜一个永远在构想中的「完美」研究

### 3.6 锚定效应（Anchoring Effect）

**表现**：
- 第一个想到的 idea 占据过大的权重
- 后续的 idea 都与第一个进行比较，而非独立评估
- 难以跳脱最初的思维框架

**防范方法**：
- 刻意将第一个 idea 放到最后评估
- 使用多种发想框架，确保有不同类型的候选
- 请不同的人分别提出他们的排序
- 打散评估顺序，避免顺序效应

## 四、收敛流程检查清单

### 淘汰阶段
- [ ] 过一遍所有候选 idea 的淘汰条件
- [ ] 被淘汰的 idea 标记了原因
- [ ] 不确定的 idea 暂时保留

### 合并阶段
- [ ] 两两比较所有存活的 idea
- [ ] 标记可合并的配对
- [ ] 评估合并后的效果
- [ ] 合并后的 idea 更新描述

### 精炼阶段
- [ ] 每个候选都有具体的问题定义
- [ ] 每个候选都有初步的方法构想
- [ ] 每个候选都列出预期贡献
- [ ] 每个候选都有初步的实验计划

### 评分阶段
- [ ] 所有候选都完成五维度评分
- [ ] 计算加权总分
- [ ] 按总分排序

### 决策阶段
- [ ] 比较前 2-3 名候选
- [ ] 考量直觉判断
- [ ] 考量策略因素
- [ ] 检查认知偏误
- [ ] 做出最终选择
- [ ] 撰写 1-page 提案
