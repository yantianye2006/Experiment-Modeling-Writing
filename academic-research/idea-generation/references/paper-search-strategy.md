# 文献搜索策略

本文件说明如何系统化地搜索文献，以验证研究 idea 的新颖性并建立相关工作的知识基础。

---

## 一、关键字设计

关键字的品质直接决定搜索的效率与覆盖率。好的关键字组合能帮助你快速定位最相关的文献。

### 1.1 核心关键字提取

从你的研究 idea 中提取以下类型的关键字：

| 类型 | 说明 | 范例 |
|------|------|------|
| 方法关键字 | 使用的技术或演算法 | transformer, diffusion model, contrastive learning |
| 问题关键字 | 要解决的问题或任务 | text summarization, object detection, drug discovery |
| 领域关键字 | 研究的学科领域 | NLP, computer vision, bioinformatics |
| 资料关键字 | 使用的资料类型或资料集 | clinical notes, satellite images, ImageNet |

### 1.2 同义词与相关词扩展

为每个核心关键字列出同义词、上位词与下位词：

```
核心关键字：text summarization
├── 同义词：document summarization, automatic summarization
├── 上位词：text generation, natural language generation
├── 下位词：extractive summarization, abstractive summarization,
│           multi-document summarization
└── 相关词：information compression, key point extraction
```

### 1.3 关键字组合策略

使用布林运算子组合关键字：

- **AND**：缩小范围，如 `"diffusion model" AND "text generation"`
- **OR**：扩大范围，如 `"summarization" OR "compression"`
- **NOT**：排除不相关，如 `"transformer" NOT "electrical"`
- **引号**：精确匹配，如 `"chain of thought"`

### 1.4 迭代式关键字调整

搜索是一个迭代过程：

1. 用初始关键字搜索
2. 从找到的论文中学习新的术语
3. 用新术语更新关键字
4. 重复直到不再发现新的相关文献

## 二、搜索工具推荐

### 2.1 Semantic Scholar

- **网址**：https://www.semanticscholar.org
- **特色**：
  - 语义搜索，能理解查询意图
  - 提供论文影响力指标（Highly Influential Citations）
  - API 支援，可程式化搜索
  - TLDR 功能，快速了解论文重点
- **适用场景**：探索性搜索、寻找高影响力论文
- **使用技巧**：
  - 使用自然语言查询，不需要布林运算子
  - 利用 "Fields of Study" 筛选领域
  - 关注 "Highly Influential" 引用，而非总引用数
  - 使用 Research Feed 追踪特定主题

### 2.2 Google Scholar

- **网址**：https://scholar.google.com
- **特色**：
  - 覆盖面最广，包含各种来源
  - 引用追踪功能完善
  - "Cited by" 与 "Related articles" 功能
  - 可设定提醒（Alert）
- **适用场景**：确认性搜索、引用追踪
- **使用技巧**：
  - 使用 `allintitle:` 搜索标题中包含特定词的论文
  - 使用 `author:` 搜索特定作者
  - 使用 "Since [year]" 筛选近期论文
  - 建立 Google Scholar Profile 追踪领域动态
  - 使用 Google Scholar Alerts 追踪特定关键字

### 2.3 arXiv

- **网址**：https://arxiv.org
- **特色**：
  - 预印本平台，论文最先出现的地方
  - 完全开放存取
  - 每日更新
  - 可按领域浏览（cs.CL, cs.CV, cs.LG 等）
- **适用场景**：追踪最新研究、寻找尚未正式发表的工作
- **使用技巧**：
  - 使用 arXiv Sanity（或类似工具）进行语义搜索
  - 订阅相关分类的每日邮件通知
  - 使用 Papers With Code 找到对应的程式码
  - 注意：arXiv 论文未经同行审查，品质参差不齐

### 2.4 DBLP

- **网址**：https://dblp.org
- **特色**：
  - 电脑科学领域最完整的书目索引
  - 可按作者、会议、期刊浏览
  - 资料结构化，适合批量分析
- **适用场景**：确认论文的正式发表版本、查找某作者的完整发表记录
- **使用技巧**：
  - 在 DBLP 上确认论文是否已被顶会/顶刊接收
  - 浏览特定会议的历年论文列表

### 2.5 ACL Anthology

- **网址**：https://aclanthology.org
- **特色**：
  - 自然语言处理领域的专用资料库
  - 所有 ACL 系列会议的论文
  - 完全开放存取
- **适用场景**：NLP 领域的深入文献搜索

### 2.6 其他工具

| 工具 | 用途 |
|------|------|
| Connected Papers | 视觉化论文之间的关联 |
| Research Rabbit | 探索相关论文，类似推荐系统 |
| Elicit | 使用 AI 从论文中提取资讯 |
| Litmaps | 建立视觉化的文献地图 |
| Papers With Code | 查找论文对应的程式码与排行榜 |

## 三、滚雪球法（Snowballing）

滚雪球法是一种从已知论文出发，逐步扩展文献搜索范围的方法。

### 3.1 前向滚雪球（Forward Snowballing）

从一篇已知的重要论文出发，查看引用了它的后续论文。

**操作方式**：
1. 找到一篇你的 idea 的核心相关论文（称为「种子论文」）
2. 在 Google Scholar 或 Semantic Scholar 上查看 "Cited by"
3. 浏览引用列表，挑选标题看起来相关的论文
4. 按时间排序，重点看最近的引用
5. 对新找到的相关论文重复此步骤

**目的**：
- 找到种子论文之后的发展方向
- 确认你的 idea 是否已被后续工作实现
- 了解这个方向的最新进展

### 3.2 后向滚雪球（Backward Snowballing）

从一篇论文的参考文献列表出发，追溯它引用的工作。

**操作方式**：
1. 阅读种子论文的 Related Work 段落
2. 浏览参考文献列表
3. 挑选被重复引用或被强调的论文
4. 对新找到的论文重复此步骤

**目的**：
- 找到这个研究方向的基础工作
- 理解问题的历史演进
- 发现可能被忽略的早期工作

### 3.3 作者追踪（Author Tracking）

追踪关键论文的作者及其研究团队。

**操作方式**：
1. 找到核心论文的第一作者和通讯作者
2. 查看他们的 Google Scholar Profile 或个人网页
3. 浏览他们的其他论文
4. 关注他们的最新工作

**目的**：
- 了解这个方向的主要研究团队
- 预判他们可能的下一步研究方向
- 避免与活跃的团队正面竞争（或寻求合作）

### 3.4 滚雪球法的终止条件

当以下情况出现时，可以停止滚雪球：

- 新找到的论文不再与你的 idea 直接相关
- 同一批论文被反复出现（搜索饱和）
- 已经覆盖了该方向的主要研究团队
- 建立了一个涵盖 15-30 篇核心论文的文献表

## 四、如何判断一篇论文的重要性

在搜索到大量论文后，需要快速判断哪些是重要的。以下提供几个评估维度。

### 4.1 发表场所

论文发表的场所是品质的一个重要指标（但不是唯一指标）。

**顶级会议/期刊的参考**：
- **机器学习**：NeurIPS, ICML, ICLR
- **自然语言处理**：ACL, EMNLP, NAACL
- **电脑视觉**：CVPR, ICCV, ECCV
- **人工智慧**：AAAI, IJCAI
- **资料探勘**：KDD, WWW, SIGIR
- **期刊**：JMLR, TPAMI, TACL, Nature Machine Intelligence

**注意**：
- arXiv 预印本可能品质极高，也可能品质极低
- Workshop papers 通常是初步工作，但可能包含新颖想法
- 被拒的论文不代表没有价值

### 4.2 引用数量与品质

- **引用数量**：高引用通常表示高影响力，但需考虑论文的年龄
- **引用速度**：短时间内快速累积引用的论文值得关注
- **引用品质**：被顶会论文引用 vs 被低品质论文引用
- **Semantic Scholar 的 "Highly Influential Citations"**：特别有参考价值

### 4.3 快速阅读策略

对于搜索到的大量论文，使用以下策略快速判断重要性：

1. **读标题**（5 秒）：是否直接相关？
2. **读摘要**（30 秒）：问题、方法、结果是否与你的 idea 相关？
3. **看图表**（1 分钟）：主要结果是什么？架构是什么？
4. **读结论**（1 分钟）：主要贡献与限制是什么？
5. **读 Introduction 最后一段**（1 分钟）：作者自述的贡献列表

如果通过以上五步仍觉得相关，再花时间详细阅读。

### 4.4 论文分类

将找到的论文按照与你 idea 的关系进行分类：

| 分类 | 说明 | 行动 |
|------|------|------|
| 直接相关 | 做的事情与你的 idea 高度重叠 | 仔细阅读，评估差异 |
| 方法相关 | 使用类似的方法但解决不同问题 | 学习方法细节 |
| 问题相关 | 解决类似的问题但使用不同方法 | 作为 baseline 参考 |
| 间接相关 | 提供背景知识或理论基础 | 选择性阅读 |
| 不相关 | 主题不相关 | 排除 |

## 五、搜索流程总结

### 完整搜索流程检查清单

- [ ] 从 idea 中提取核心关键字（方法、问题、领域、资料）
- [ ] 为每个核心关键字列出同义词与相关词
- [ ] 设计 3-5 组关键字组合
- [ ] 在 Semantic Scholar 上进行探索性搜索
- [ ] 在 Google Scholar 上进行确认性搜索
- [ ] 在 arXiv 上搜索最新预印本
- [ ] 选择 2-3 篇种子论文进行滚雪球
- [ ] 执行前向滚雪球（查看被引用）
- [ ] 执行后向滚雪球（查看参考文献）
- [ ] 追踪关键作者的其他工作
- [ ] 对找到的论文进行分类与重要性评估
- [ ] 确认搜索饱和（不再发现新的相关论文）
- [ ] 更新 idea 的新颖性判定
- [ ] 建立结构化的文献表

### 搜索时间建议

| 步骤 | 建议时间 |
|------|----------|
| 关键字设计 | 15-30 分钟 |
| 多平台搜索 | 1-2 小时 |
| 滚雪球法 | 1-2 小时 |
| 论文分类与评估 | 1-2 小时 |
| **每个 idea 合计** | **3-6 小时** |

### 常见错误

1. **关键字过于狭窄**：只搜索自己熟悉的术语，遗漏其他社群的工作
2. **只看最新论文**：忽略了经典的早期工作
3. **只搜索英文文献**：某些领域有重要的非英文文献
4. **确认偏误搜索**：只搜索支持自己 idea 的文献，忽略反面证据
5. **过早停止**：找到几篇相关论文就停止，未达搜索饱和
6. **过度搜索**：无止境地搜索导致迟迟无法进入下一阶段
