# 公式与图表解读指南

本指南提供太奶在「步骤四：公式图表解读」时使用的解说策略和模板。

---

## 公式解释三步骤模板

每个公式都按照以下三步骤解释：

### 第一步：先说直觉

用一句白话文告诉读者这个公式「在干嘛」。不用任何数学符号，就像在跟完全不懂数学的人聊天。

**模板**：
> 这个公式在做的事情就是「___」。

**范例**：
- Loss function：「这个公式在衡量模型的预测跟正确答案差了多远，差越多分数越高，模型就要更努力改进。」
- Attention：「这个公式在计算每个字应该要多注意其他哪些字，就像你在读句子时，眼睛会自动盯著重要的词看。」
- Softmax：「这个公式把一堆数字压缩成机率，让它们加起来等于 1，这样就能当成『信心分数』来用。」

### 第二步：再拆符号

把公式中的每个符号都列出来解释。用表格或列表呈现，让读者可以对照著看。

**模板**：

| 符号 | 念法 | 意思 | 太奶的比喻 |
|------|------|------|-----------|
| x | x | 输入资料 | 食材 |
| θ | theta | 模型参数 | 食谱上的调味比例 |
| L | L | 损失值 | 顾客的不满意度 |

**注意事项**：
- 不要跳过任何符号，包括下标和上标
- 如果符号在前文已定义过，简单提一下在哪里定义的即可
- 希腊字母要附上英文念法

### 第三步：最后讲意义

回答三个问题：
1. 这个公式为什么重要？
2. 如果没有这个公式（或改成别的），会怎样？
3. 这个公式有什么限制或假设？

## 常见公式类型的解说策略

### Loss Function（损失函数）

**核心直觉**：衡量「模型有多差」的分数，目标是让它越小越好。

**解说重点**：
- 为什么选这个 loss 而不是别的？
- 这个 loss 鼓励模型学到什么行为？
- 有没有正则化项？正则化在做什么？

**太奶常用比喻**：
- 「Loss 就像你考试的扣分，答错越多扣越多，你的目标就是少扣一点」
- 「Cross-entropy loss 就像老师在看你的答案分布跟标准答案的分布差多少」
- 「L2 regularization 就像太奶规定你每道菜的调味料不能加太多，免得太重口味」

**常见 loss 的速查表**：

| Loss 名称 | 直觉 | 用途 |
|-----------|------|------|
| MSE (Mean Squared Error) | 预测值和真实值的距离平方平均 | 回归任务 |
| Cross-Entropy | 两个机率分布的差异 | 分类任务 |
| Binary Cross-Entropy | Cross-Entropy 的二分类版 | 二分类/多标签 |
| Contrastive Loss | 让相似的靠近、不同的远离 | 对比学习 |
| Triplet Loss | 让 anchor 更靠近正样本、远离负样本 | 度量学习 |
| KL Divergence | 两个分布的不对称差异 | VAE / 知识蒸馏 |
| Hinge Loss | 分类边界的间隔大小 | SVM / ranking |

---

### Attention Mechanism（注意力机制）

**核心直觉**：让模型「决定要看哪里」。

**解说重点**：
- Query, Key, Value 分别代表什么？
- Attention score 怎么算出来的？
- Multi-head attention 的多个 head 各自在看什么？

**太奶常用比喻**：
- 「Attention 就像太奶在菜市场买菜，眼睛会自动盯著新鲜的蔬菜看（高 attention），烂掉的就忽略（低 attention）」
- 「Query 是你的问题，Key 是每个候选答案的标签，Value 是答案的内容。你拿问题去跟每个标签比对，最像的答案就拿出来用」
- 「Multi-head 就像你同时派 8 个侦探去调查，每个人从不同角度找线索，最后汇整报告」

**标准公式拆解**：

```
Attention(Q, K, V) = softmax(QK^T / √d_k) V
```

| 符号 | 意思 | 比喻 |
|------|------|------|
| Q | Query 矩阵 | 你想问的问题 |
| K | Key 矩阵 | 每个候选者的名牌 |
| V | Value 矩阵 | 每个候选者实际携带的资讯 |
| d_k | Key 的维度 | 名牌上的字数（用来正规化） |
| QK^T | Query 和 Key 的相似度 | 问题和名牌的匹配程度 |
| softmax | 转换成机率 | 把匹配分数变成「要分配多少注意力」 |
| √d_k | 缩放因子 | 防止分数太大导致 softmax 太极端 |

---

### Optimization（优化相关）

**核心直觉**：怎么一步步调整模型，让它越来越好。

**解说重点**：
- 用的是哪种优化器？（SGD、Adam、AdamW……）
- Learning rate 怎么设定？有没有 schedule？
- 有没有特殊的训练策略？（warmup、gradient clipping……）

**太奶常用比喻**：
- 「Gradient descent 就像下山，你站在山上往最陡的方向走，一步步走到山谷」
- 「Learning rate 就像你的步伐大小，太大会跨过山谷、太小会走到天荒地老」
- 「Adam 就像一个聪明的登山者，他会记住之前走过的路，自动调整步伐」
- 「Warmup 就像运动前的热身，一开始慢慢走，热开了再加速」

---

### Probability & Statistics（机率统计相关）

**核心直觉**：用数学语言描述「不确定性」。

**解说重点**：
- 条件机率 P(A|B) 的直觉
- 贝氏定理在论文中扮演的角色
- Expectation、Variance 的意义

**太奶常用比喻**：
- 「P(下雨|乌云) 就是『看到乌云时，下雨的机会有多大』」
- 「期望值就像你考很多次试的平均成绩」
- 「变异数就像你的成绩稳不稳定——有时 100 有时 30 的孩子，变异数很大」

## 图表解读方法

### 通用三步骤

#### 1. 看趋势（Trend）
- 整体走势是上升、下降、还是持平？
- 有没有明显的转折点？
- 太奶的问法：「这张图大致在告诉你什么方向？」

#### 2. 找异常（Anomaly）
- 有没有特别突出或凹下去的点？
- 有没有跟其他线差异很大的地方？
- 太奶的问法：「有没有哪里看起来怪怪的？」

#### 3. 连结文字（Context）
- 图表呈现的结果跟文字描述一致吗？
- 有没有图表显示了但文字没提到的现象？
- 太奶的问法：「作者有没有老实地报告所有结果？」

---

### 常见图表类型解读

#### 训练曲线（Training Curve）
- **X 轴**：通常是 epoch 或 step
- **Y 轴**：通常是 loss 或 accuracy
- **要注意**：
  - 有没有收敛？收敛速度如何？
  - 有没有 overfitting 的迹象？（training loss 下降但 validation loss 上升）
  - 不同方法的收敛速度比较

#### 柱状图（Bar Chart）
- 通常用来比较不同方法在不同指标上的表现
- **要注意**：
  - Y 轴有没有从 0 开始？（有些论文会截断 Y 轴来放大差异）
  - 有没有 error bar？（没有的话结果可信度较低）
  - 差异在统计上是否显著？

#### 表格（Table）
- 主要实验结果的载体
- **要注意**：
  - 粗体通常标记最佳结果
  - 底线通常标记次佳结果
  - 注意看 table caption，常常有重要资讯

#### 注意力视觉化（Attention Visualization）
- 展示模型「在看哪里」
- **要注意**：
  - 注意力分布是否合理？（看的地方跟人类直觉一致吗？）
  - 不同 head 的注意力有没有差异？
  - 太奶会说：「你看，模型真的有在看重要的地方，不是乱猜的」

#### t-SNE / UMAP 图
- 把高维特征投影到 2D 来看分群效果
- **要注意**：
  - 同类别的点有没有聚在一起？
  - 不同类别之间有没有清楚的边界？
  - 太奶会说：「你看，同一类的都黏在一起，不同类的离得远远的，表示模型学到了好的特征」

## 太奶的公式教学原则

1. **先讲结论再讲过程** — 不要一上来就拆公式，先告诉读者「这个公式算出来的东西是什么」
2. **用类比打底** — 每个公式至少一个生活比喻
3. **符号表要完整** — 不能有任何一个符号被漏掉
4. **不怕重复** — 如果某个概念前面讲过，再简短提一次也没关系
5. **承认不确定** — 如果公式的某个设计选择太奶也不确定为什么，就诚实说
6. **连结前后文** — 告诉读者这个公式跟前面/后面的公式是什么关系
