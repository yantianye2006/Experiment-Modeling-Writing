## 三、随机种子与确定性

### 必要揭露项目

- [ ] 是否设定了随机种子
- [ ] 随机种子的具体值
- [ ] 使用了几个不同的随机种子

### 建议揭露项目

- [ ] 所有随机性来源的种子设定方式
- [ ] 是否启用确定性模式（deterministic mode）
- [ ] 已知的非确定性来源及其影响

### 随机性来源清单

需要控制的随机性来源包括：

1. **Python 内建随机数**：`random.seed()`
2. **NumPy 随机数**：`np.random.seed()`
3. **PyTorch CPU 随机数**：`torch.manual_seed()`
4. **PyTorch GPU 随机数**：`torch.cuda.manual_seed_all()`
5. **cuDNN 确定性**：`torch.backends.cudnn.deterministic = True`
6. **cuDNN 基准测试**：`torch.backends.cudnn.benchmark = False`
7. **资料载入器**：DataLoader 的 `worker_init_fn` 和 `generator`
8. **环境变数**：`PYTHONHASHSEED`

### 范例程式码

```python
import random
import numpy as np
import torch

def set_seed(seed: int):
    random.seed(seed)
    np.random.seed(seed)
    torch.manual_seed(seed)
    torch.cuda.manual_seed_all(seed)
    torch.backends.cudnn.deterministic = True
    torch.backends.cudnn.benchmark = False
    os.environ['PYTHONHASHSEED'] = str(seed)

# 使用的种子列表：42, 123, 456, 789, 1024
```

### 多次实验报告格式

```

1024   | 88.4   | 89.8
-------|--------|------
平均   | 88.24  | 89.64
标准差 | ±0.23  | ±0.23
```

## 八、完整可重现性检查流程

在提交论文前，按以下流程进行最终检查：

### 第一轮：文件检查

1. 论文中是否包含所有必要的实验细节？
2. 附录中是否有完整的超参数表？
3. 是否提供了程式码连结？

### 第二轮：独立重现测试

1. 请一位未参与研究的同事尝试依照论文描述重现结果
2. 记录重现过程中遇到的问题
3. 根据回馈补充缺漏的细节

### 第三轮：程式码检查

1. 程式码能否在干净的环境中从零开始执行？
2. README 的指令是否完整且正确？
3. 随机种子设定是否生效？

## 九、常见可重现性问题与解决方案

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 结果每次不同 | 随机性未完全控制 | 检查所有随机性来源的种子设定 |
| 无法安装套件 | 版本冲突 | 提供完整的 requirements.txt 或 Docker |
| 结果与论文差异大 | 训练细节遗漏 | 逐一比对所有超参数与设定 |
| GPU 不同导致结果不同 | 浮点运算差异 | 记录硬体资讯，接受小幅差异 |
| 资料集版本不同 | 资料集更新 | 明确记录资料集版本与下载连结 |
