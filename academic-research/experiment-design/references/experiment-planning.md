# 实验规划方法

## 概述

本文件提供从研究假设到实验流程的详细规划方法，涵盖假设撰写、变数定义与控制的完整指引。

---

## 一、如何写好研究假设

### 1.1 研究假设的角色

研究假设是整个实验设计的锚点。一个好的假设能够：

- 明确实验的目标与方向
- 决定需要哪些实验来验证
- 引导评估指标的选择
- 框定论文的贡献范围

### 1.2 假设的层次结构

```
总假设（Main Hypothesis）
├── 子假设 H1：效能假设
│   ├── H1a：在资料集 A 上的表现
│   └── H1b：在资料集 B 上的表现
├── 子假设 H2：效率假设
└── 子假设 H3：泛化假设
```

建议将一个复杂的研究假设拆解为 2-5 个子假设，每个子假设对应一组实验。

### 1.3 假设撰写的步骤

**第一步：厘清研究问题**

- 现有方法存在什么问题？
- 你提出了什么解决方案？
- 为什么你的方案可能有效？

**第二步：撰写初版假设**

使用以下模板：

> 我们假设 [提出的方法/机制]，因为 [理论依据/直觉]，所以在 [任务/资料集] 上，[评估指标] 相较于 [比较对象] 将 [提升/降低] [预期幅度]。

**第三步：检查假设品质**

- 可证伪性检查：什么样的实验结果会否定这个假设？
- 具体性检查：假设是否包含可量化的预期？
- 范围检查：假设的适用范围是否清楚？

**第四步：精炼假设**

根据检查结果修改假设，使其更加精确。

### 1.4 常见假设类型

| 假设类型 | 范例 |
|----------|------|
| 效能假设 | 「方法 X 在任务 T 上的 F1 优于 SOTA 方法 Y」 |
| 效率假设 | 「方法 X 在达到相近效能时，推论速度快于方法 Y 两倍」 |
| 组件假设 | 「模组 A 是方法 X 效能提升的关键因素」 |
| 泛化假设 | 「方法 X 在未见过的领域 D 上仍能保持效能优势」 |
| 规模假设 | 「方法 X 的效能增益随资料规模增加而扩大」 |

### 1.5 假设撰写的常见错误

1. **过于模糊**：「我们的方法表现更好」——缺乏具体指标与比较对象
2. **不可证伪**：「我们的方法在某些情况下可能有帮助」——永远不会被否定
3. **过于野心**：「我们的方法在所有任务上都是最佳的」——范围过广
4. **缺乏理论支撑**：没有解释为什么预期假设成立
5. **与实验脱节**：假设无法被计划中的实验验证

## 二、从假设到实验流程

### 2.1 假设-实验对应矩阵

建立假设与实验的对应关系表：

| 假设 | 对应实验 | 评估指标 | 预期结果 |
|------|----------|----------|----------|
| H1：效能假设 | 主实验表 | F1, Acc | 提升 2+ 点 |
| H2：组件假设 | Ablation Study | F1 差异 | 移除后下降 |
| H3：泛化假设 | 跨资料集实验 | F1 | 维持优势 |

### 2.2 实验流程设计

**阶段一：预实验（Pilot Experiments）**

- 目的：验证程式码正确性、确认实验可行性
- 规模：使用小资料集或资料子集
- 时间：总实验时间的 10-15%

**阶段二：主实验（Main Experiments）**

- 目的：验证核心假设
- 包含：与所有 Baseline 的比较
- 要求：多次随机种子、完整资料集

**阶段三：分析实验（Analysis Experiments）**

- Ablation Study
- 超参数敏感度分析
- 定性分析与可视化

**阶段四：补充实验（Supplementary Experiments）**

- 跨资料集迁移
- 效率分析
- 审稿人可能要求的追加实验

### 2.3 实验优先顺序

建议按以下优先顺序安排实验：

1. 预实验（确认可行性）
2. 核心 Baseline 比较（验证主假设）
3. 完整消融实验（验证组件假设）
4. 超参数敏感度分析
5. 跨资料集迁移实验
6. 定性分析与可视化
7. 效率分析

## 三、变数控制的原则

### 3.1 单一变数原则

**核心精神**：每次实验中，仅改变一个自变数，其余所有条件保持不变。

这是实验设计最基本也是最重要的原则。违反此原则会导致无法判断效能变化的真正原因。

**正确范例**：

```
实验 A（基线）：模型 = Transformer, 学习率 = 1e-4, 批次大小 = 32
实验 B（改变模型）：模型 = 我们的方法, 学习率 = 1e-4, 批次大小 = 32
```

**错误范例**：

```
实验 A：模型 = Transformer, 学习率 = 1e-4, 批次大小 = 32
实验 B：模型 = 我们的方法, 学习率 = 3e-4, 批次大小 = 64
→ 无法判断效能差异来自模型还是超参数
```

### 3.2 完整记录原则

所有变数（包括看似不重要的）都必须记录，包括：

- 环境变数（硬体、软体版本）
- 随机性相关（种子值、资料打乱顺序）
- 隐含变数（资料载入顺序、GPU 计算的非确定性）

### 3.3 合理范围原则

自变数的取值范围应该：

- 基于先前研究或理论推导
- 覆盖实际应用中可能遇到的范围
- 包含足够的取值点以观察趋势

### 3.4 控制变数清单

以下是机器学习实验中常见的控制变数：

**资料相关**

- 训练 / 验证 / 测试集切分
- 资料前处理流程
- 资料增强策略
- 词汇表大小与建构方式

**模型相关**

- 预训练模型版本与权重
- 隐藏层维度
- 层数
- 注意力头数

**训练相关**

- 优化器类型与参数
- 学习率排程
- 批次大小
- 训练轮数或步数
- 早停策略
- 梯度裁剪

**评估相关**

- 评估频率
- 模型选择准则（如最佳验证集表现）
- 解码策略（如 beam search 的 beam size）

### 3.5 当无法完全控制变数时

某些情况下，完全控制所有变数并不可行：

- **对策一**：明确记录无法控制的变数，并在论文中说明
- **对策二**：透过多次实验取平均来减少随机性的影响
- **对策三**：进行敏感度分析，确认无法控制的变数对结果的影响程度

## 四、实验设计检查要点

### 设计阶段

- [ ] 所有假设都已明确撰写
- [ ] 假设-实验对应矩阵已建立
- [ ] 自变数、依变数、控制变数已定义
- [ ] 实验流程与优先顺序已确定

### 执行前

- [ ] 程式码已通过小规模预实验验证
- [ ] 随机种子列表已确定
- [ ] 计算资源已确认足够
- [ ] 结果记录格式已准备好

### 执行中

- [ ] 每次实验的完整设定已记录
- [ ] 中间结果定期备份
- [ ] 异常结果已标记并调查

### 执行后

- [ ] 所有假设都有对应的实验结果
- [ ] 统计检验已完成
- [ ] 结果的解读与假设一致或有合理解释
