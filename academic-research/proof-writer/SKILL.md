# proof-writer：数学证明撰写技能

## 概述

本技能专注于学术论文中的数学证明撰写。涵盖从主张提取、策略选择到完整 LaTeX
排版的端对端工作流程。所有解释使用简体中文，数学表达式与 LaTeX 代码使用英文。

---

## 流程总览

证明撰写分为五个阶段，依序执行：

```
主张提取 → 文献扫描 → 策略选择 → 逐步推导 → LaTeX 排版
```

每个阶段有明确的输入、输出与品质检查点。以下逐一说明。

---

## 第一阶段：主张提取

### 目的

从论文草稿或用户输入中，精确提取需要证明的数学主张。主张必须是形式化的命题，
具备明确的前提条件与结论。

### 步骤

1. **辨识主张类型**：判断是定理 (Theorem)、引理 (Lemma)、推论 (Corollary)、
   命题 (Proposition)，还是声明 (Claim)。
2. **提取前提条件**：列出所有假设、约束条件与适用范围。
3. **提取结论**：明确写出要证明的等式、不等式或性质。
4. **符号确认**：确认所有符号的定义与范围，参照
   [符号惯例](references/notation-conventions.md)。
5. **形式化陈述**：将主张写成标准的数学陈述格式。

### 输出格式

```
主张类型：[Theorem | Lemma | Corollary | Proposition | Claim]
前提条件：
  - 条件 1
  - 条件 2
  - ...
结论：[形式化的数学陈述]
相关符号：[符号清单及定义]
```

### 常见问题

- 前提条件不完整：回头检查论文中的假设段落。
- 符号未定义：查阅论文的 notation section 或向用户确认。
- 主张过于模糊：要求用户提供更精确的形式化陈述。

### 品质检查

- [ ] 主张是否为可判定的数学命题？
- [ ] 所有符号是否已定义？
- [ ] 前提条件是否足以推导结论？
- [ ] 主张类型是否正确分类？

---

## 第二阶段：文献扫描

### 目的

查找与主张相关的已知定理、引理和结果，为证明建立基础。这一步决定了我们可以
「站在哪些巨人的肩膀上」。

### 步骤

1. **关键词提取**：从主张中提取数学关键词（如 convergence、bound、
   concentration inequality 等）。
2. **定理匹配**：在已知定理库中搜索相关结果，参照
   [定理连结方法](references/theorem-connection.md)。
3. **相关性评估**：评估每个找到的定理与当前主张的相关程度。
4. **依赖关系建立**：确定哪些定理可以直接使用，哪些需要适度修改。
5. **缺口分析**：找出已知结果与目标主张之间的差距。

### 常用定理来源

- 论文自身前文已证明的引理
- 论文引用的参考文献
- 领域内的经典结果（如 Cauchy-Schwarz, Jensen's inequality 等）
- 标准教科书中的基础定理

### 输出格式

```
相关定理：
  1. [定理名称] — [简述] — 相关度：[高|中|低]
  2. ...
可直接引用：[定理列表]
需要修改后使用：[定理列表及修改方向]
证明缺口：[需要自行推导的部分]
```

### 品质检查

- [ ] 是否遗漏了重要的已知结果？
- [ ] 引用的定理前提条件是否满足？
- [ ] 定理的版本是否正确（有些定理有多个变体）？

---

## 第三阶段：策略选择

### 目的

根据主张的结构和可用的已知结果，选择最合适的证明策略。策略的选择直接影响
证明的清晰度和长度。

### 可用策略

本技能支援以下八种证明策略，每种策略的详细说明见
[证明策略参考](references/proof-strategies.md)。

#### 1. 直接证明 (Direct Proof)

从前提条件出发，通过一系列逻辑推导直接到达结论。适用于结构清晰、推导路径
明确的主张。

**适用场景**：等式证明、不等式推导、集合包含关系。

#### 2. 反证法 (Proof by Contradiction)

假设结论不成立，推导出矛盾。适用于直接证明困难或结论为否定形式的主张。

**适用场景**：存在性的否定、唯一性证明、不可能性结果。

#### 3. 数学归纳法 (Mathematical Induction)

对自然数或可良序化的结构进行归纳。包括弱归纳、强归纳和结构归纳。

**适用场景**：递回结构、序列性质、离散数学中的命题。

#### 4. 构造性证明 (Constructive Proof)

明确构造出满足条件的对象，从而证明存在性。比纯存在性证明提供更多资讯。

**适用场景**：存在性命题、算法正确性、具体界的建立。

#### 5. 归约法 (Proof by Reduction)

将要证明的问题归约为已知的问题。常用于计算复杂度和决策问题。

**适用场景**：NP-hardness 证明、下界证明、等价性证明。

#### 6. 机率法 (Probabilistic Method)

通过证明随机选择满足条件的机率大于零，从而证明满足条件的对象存在。

**适用场景**：组合数学、图论、随机化算法分析。

#### 7. 凸性论证 (Convexity Arguments)

利用凸函数或凸集的性质进行推导。在最佳化和机器学习理论中尤其常见。

**适用场景**：最佳化问题、Jensen's inequality 的应用、凸松弛。

#### 8. 资讯论方法 (Information-theoretic Methods)

使用熵、互资讯、KL 散度等资讯论工具进行推导。

**适用场景**：通讯理论、学习理论下界、隐私分析。

### 策略选择决策树

```
主张结构分析
├─ 等式或不等式？
│  ├─ 是 → 考虑直接证明、凸性论证
│  └─ 否 → 继续
├─ 存在性命题？
│  ├─ 是 → 考虑构造性证明、机率法
│  └─ 否 → 继续
├─ 涉及递回或序列？
│  ├─ 是 → 考虑数学归纳法
│  └─ 否 → 继续
├─ 可归约为已知问题？
│  ├─ 是 → 考虑归约法
│  └─ 否 → 继续
├─ 涉及资讯量度？
│  ├─ 是 → 考虑资讯论方法
│  └─ 否 → 继续
└─ 直接证明困难？
   ├─ 是 → 考虑反证法
   └─ 否 → 使用直接证明
```

### 复合策略

许多复杂的证明需要组合多种策略。常见的组合包括：

- **归纳 + 直接**：归纳步骤中使用直接证明
- **反证 + 构造**：假设不存在，然后构造出矛盾的对象
- **归约 + 资讯论**：归约到资讯论问题后使用资讯论工具

### 输出格式

```
选择策略：[主要策略名称]
辅助策略：[如有]
选择理由：[为什么这个策略最适合]
预期证明结构：[大纲]
预期难度：[低|中|高]
```

## 第四阶段：逐步推导

### 目的

根据选定的策略，撰写完整、严谨的证明过程。每一步都必须有明确的逻辑依据。

### 原则

1. **完整性**：不跳过任何非显而易见的步骤。
2. **严谨性**：每一步推导必须有明确的数学依据。
3. **可读性**：使用清晰的语言引导读者。
4. **模组化**：复杂的证明应拆分为多个引理。

### 撰写规范

#### 推导步骤格式

每一步推导应包含：

- **陈述**：本步骤要建立的中间结论
- **推导**：具体的数学推导过程
- **依据**：引用的定理、引理或之前的步骤

#### 过渡语句

在步骤之间使用适当的过渡语句，引导读者理解证明的逻辑流程：

- "By assumption, ..."
- "It follows from Theorem X that ..."
- "Combining (1) and (2), we obtain ..."
- "Without loss of generality, ..."
- "By the definition of ..., we have ..."

#### 常见警告

- 避免使用 "clearly"、"obviously"、"trivially" 来跳过步骤。
- 如果一个步骤需要超过三行的推导，考虑将其提取为独立的引理。
- 确保所有变数在使用前已定义。
- 确保量词 (for all, there exists) 的作用域明确。

### 品质检查

- [ ] 每一步推导是否都有明确的逻辑依据？
- [ ] 是否有未说明的假设？
- [ ] 量词的使用是否正确？
- [ ] 符号是否与论文其余部分一致？
- [ ] 证明是否完整（以 QED 或 $\square$ 结尾）？

## 第五阶段：LaTeX 排版

### 目的

将证明转换为可直接插入论文的 LaTeX 代码。排版应符合学术论文的标准格式。

### 排版规范

详细的 LaTeX 排版模式见 [LaTeX 数学排版参考](references/latex-math-patterns.md)。

#### 基本环境

```latex
\begin{theorem}[Theorem Name]
\label{thm:theorem-label}
  Statement of the theorem.
\end{theorem}

\begin{proof}
  Proof content here. \qed
\end{proof}
```

#### 编号与引用

- 所有定理、引理、推论都必须有 `\label`。
- 使用 `\ref` 或 `\eqref` 进行交叉引用。
- 等式编号使用 `equation` 或 `align` 环境。

#### 排版风格

- 行内公式使用 `$...$`。
- 展示公式使用 `\[...\]` 或有编号的环境。
- 多行对齐使用 `align` 环境。
- 分情况讨论使用 `cases` 环境。

### 输出格式

最终输出应包含：

1. 完整的 LaTeX 代码片段（可直接复制贴上）
2. 所需的额外套件列表（如 `amsthm`, `amsmath` 等）
3. 如需自定义命令，附上 `\newcommand` 定义

### 品质检查

- [ ] LaTeX 代码是否可以成功编译？
- [ ] 数学符号是否正确呈现？
- [ ] 编号和引用是否正确？
- [ ] 排版是否美观（对齐、间距等）？
- [ ] 是否符合目标期刊的格式要求？

## 使用范例

### 范例一：简单不等式证明

**输入**：证明对所有 $x > 0$，有 $e^x \geq 1 + x$。

**第一阶段输出**：

```
主张类型：Proposition
前提条件：
  - x > 0, x ∈ ℝ
结论：e^x ≥ 1 + x
相关符号：e 为自然对数的底
```

**第三阶段输出**：

```
选择策略：直接证明
选择理由：可通过分析 f(x) = e^x - 1 - x 的性质直接推导
预期证明结构：
  1. 定义 f(x) = e^x - 1 - x
  2. 计算 f'(x) = e^x - 1
  3. 分析 f 的单调性
  4. 利用 f(0) = 0 得出结论
预期难度：低
```

**第五阶段输出**：

```latex
\begin{proposition}
\label{prop:exp-lower-bound}
  For all $x > 0$, we have $e^x \geq 1 + x$.
\end{proposition}

\begin{proof}
  Define $f(x) = e^x - 1 - x$. We have $f(0) = 0$ and
  $f'(x) = e^x - 1 > 0$ for all $x > 0$. Therefore, $f$ is
  strictly increasing on $(0, \infty)$, which implies
  $f(x) > f(0) = 0$ for all $x > 0$. That is, $e^x > 1 + x$.
  \qed
\end{proof}
```

### 范例二：机器学习中的泛化界

**输入**：证明 PAC learning 框架下，有限假设类的样本复杂度上界。

**第一阶段输出**：

```
主张类型：Theorem
前提条件：
  - H 为有限假设类，|H| < ∞
  - 样本 S 由分布 D 上的 m 个 i.i.d. 样本组成
  - ε > 0, δ > 0
结论：若 m ≥ (1/ε)(ln|H| + ln(1/δ))，则以机率至少 1-δ，
      对所有 h ∈ H 有 |R(h) - R̂(h)| ≤ ε
相关符号：R(h) 为真实风险，R̂(h) 为经验风险
```

**第三阶段输出**：

```
选择策略：直接证明 + 机率法
辅助策略：归约到 Hoeffding's inequality
选择理由：经典的 union bound + concentration inequality 组合
预期证明结构：
  1. 对单一假设 h 应用 Hoeffding's inequality
  2. 对所有假设取 union bound
  3. 解出 m 的下界
预期难度：中
```

## 常见工作模式

### 模式一：完整证明撰写

用户提供主张，系统执行完整的五阶段流程，输出可直接使用的 LaTeX 代码。

### 模式二：证明修复

用户提供有问题的证明，系统诊断问题所在并修复。常见问题包括：

- 逻辑跳跃（缺少中间步骤）
- 量词错误
- 边界情况未处理
- 引用的定理前提条件不满足

### 模式三：证明翻译

将非形式化的直觉论证转换为严谨的数学证明。

### 模式四：策略咨询

用户描述要证明的目标，系统建议可能的证明策略和思路，但不撰写完整证明。

## 注意事项

1. **严谨性优先**：宁可冗长也不要跳步。读者可以略过显然的步骤，但无法填补
   缺失的步骤。
2. **符号一致性**：所有符号必须与论文其余部分一致。如有冲突，在证明开头明确
   说明。参照 [符号惯例](references/notation-conventions.md)。
3. **可编译性**：输出的 LaTeX 必须可以直接编译，不能有语法错误。
4. **学术语调**：使用正式的学术英文撰写数学部分，避免口语化表达。
5. **引用规范**：使用的所有非本文证明的结果，都必须提供引用。


## 输出语言
默认使用简体中文输出；论文标题、会议名称、方法名、模型名、专有名词、代码和公式保留原文。用户明确要求其他语言时，遵从用户要求。
